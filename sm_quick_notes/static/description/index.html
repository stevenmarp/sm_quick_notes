SM Quick Notes

A sticky notes widget for Odoo systray - quick note-taking without leaving your workflow!

Features

  • Unlimited Notes - Create as many notes as you need
  • Color-Coded - Yellow, green, blue, pink, purple colors
  • Pin Notes - Keep important notes at the top
  • Search - Find notes quickly
  • Database Persistence - Notes saved in Odoo database
  • Quick Edit - Edit notes inline
  • Drag to Reorder - Organize your notes easily

How to Use

  1. Click the notes icon in the systray
  2. Click "+" to create a new note
  3. Type your note content
  4. Choose a color by clicking the color palette
  5. Pin important notes with the pin icon
  6. Search notes using the search bar

Compatibility

Compatible with Odoo 16.0, 17.0, and 18.0
